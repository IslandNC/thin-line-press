# Security policy

This repository hosts a static website. It has no server-side code, no database, no user accounts and no forms that collect personal data.

## Reporting a problem

If you find a security issue (for example a broken or insecure link, mixed content, a script that should not be there, or a DNS or certificate problem), please use the "Report a vulnerability" button in the Security tab of this repository. This opens a private report that only the maintainer can see. Please do not open a public issue for security matters.

Include the page address, what you saw, and how to reproduce it.

## Scope

In scope: the pages served from this repository and the custom domain configured for it.

Out of scope: third-party stores and platforms linked from the site (Amazon, Kobo, Apple Books, Barnes & Noble, Smashwords, Bookshop.org and others). Please report issues there to the platform.
